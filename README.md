# Updates

Version files read by the apps' built-in update checkers. Each file is one line: the latest version number.

| File | App |
|---|---|
| mpc2liveversion.txt | MPC2Live (Mac) |
| koala2liveversion.txt | Koala2Live (Mac) |
| chopshopversion.txt | Chop Shop |
| CSexplorerversion.txt | Chop Shop Explorer |

Do not delete or rename these files: every installed copy of the apps polls them. The repo must stay public.

To announce a release, change the number in the matching file. The apps then show an Update Available alert and send users to https://ko-fi.com/duffman007/shop
